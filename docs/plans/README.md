# Plans

One implementation plan per roadmap section, named `NN-section-name.md` (e.g.
`01-first-slice.md`). Write and agree it **before** coding the section.

A plan contains:

- **Goal:** one or two sentences, and what is explicitly not included.
- **Approach:** the main design choices, with links to any new ADRs.
- **Tasks:** an ordered checklist of small tasks, each roughly one commit, with the files it
  touches and how it will be verified.
- **Acceptance:** how we'll know the section is done, beyond the
  [definition of done](../workflow/definition-of-done.md).

Tick tasks off as they're completed so an agent picking the section up later can continue.
