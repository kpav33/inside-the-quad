# Review: section 00 — Project scaffold and engineering setup

- Branch: chore/project-scaffold · Reviewed commit: 5f2b429 · Date: 2026-11-08

## Summary

The scaffold is good overall. The tooling is strict and works locally (TypeScript, ESLint, Prettier,
Vitest, Playwright, husky, commitlint). The Docker image builds and serves correctly with a working
health check, and the docs are well organised and mostly match the configs. It is **not ready to
merge yet**. The CI workflow uses `pnpm/action-setup@v4`, which predates pnpm 11 support (added in
v6), so CI will very likely fail before any check runs. The repository has no git remote, so CI has
never actually run. The first two commits also don't pass `pnpm check` on their own, against the
project's own commit rule. The other findings are should-fix or nit.

There is no plan file for section 00. This review checks the branch against the owner's stated goal:
pnpm, professional linting, formatting and testing tooling, enforced Conventional Commits, no pushes
to main outside reviewed sections, a docs/ folder for agentic development, and Docker deployment to
Coolify.

## Notes on what was verified as correct

- **Doc claims checked against the code:** TypeScript is held at 6.0 because typescript-eslint 8.72.1 peers `typescript >=4.8.4 <6.1.0` while TypeScript 7.0.2 is latest. `eslint-plugin-jsx-a11y` 6.10.2 peers ESLint `^9` at most, so the es-tooling `jsx-a11y-x` fork is justified.
- **Hooks:** the hooks table in git.md matches the hook files. The commitlint rules match the documented types, the 72-character header limit and 100-character body lines.
- **Tests:** they exercise real behaviour within their limits. The unit tests check the accessible h1 and that the lazy viewer resolves through `Suspense`. The e2e test checks the title, the h1, a visible canvas and that no page errors occur. It would catch a total WebGL failure, because that blanks the page.
- **Vite build:** three.js stays out of the initial chunk, and `index.html` has no modulepreload for the viewer chunk, so the "keep three.js lazy" rule holds.
- **CLAUDE.md, AGENTS.md and the docs:** AGENTS.md is a symlink to CLAUDE.md. Its commands table matches `package.json`. The docs index, ADR template and plan or review lifecycle are clear and useful to agents.
